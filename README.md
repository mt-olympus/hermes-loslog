# Hermes LosLog

> [!WARNING]
> ## Archived
> This Hermes/LosLog integration is no longer maintained and will receive no
> further releases. Both Hermes and LosLog are retired. Migrate logging to a
> maintained PSR-3 logger and add HTTP logging in the application where it is
> still required.

This module provides integration between [Hermes](https://github.com/mt-olympus/hermes) and
[LosLog](https://github.com/lansoweb/loslog) to automatically log the requests.
